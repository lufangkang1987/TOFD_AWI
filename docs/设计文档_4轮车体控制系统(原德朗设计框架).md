## 1. 系统概述

### 1.1 业务背景

本系统是一款面向工业无损检测（NDT）领域的 **TOFD（Time of Flight Diffraction，衍射时差法）自动焊缝检测系统**。搭载于四轮爬行器平台上，实现对焊缝内部缺陷的全自动超声检测。

### 1.2 核心功能

| 功能模块 | 说明 |
|---------|------|
| TOFD 超声检测 | A/B/C 扫描波形采集与实时显示 |
| 多通道检测 | 支持多探头并行采集（多通道模式） |
| C-Scan 成像 | 二维 C 扫描图像生成与显示 |
| 涂层厚度检测 | 附加的涂层/覆层厚度测量 |
| 涡流检测（ECT） | 集成涡流探伤模块 |
| 爬行器运动控制 | 四轮爬行器行走、纠偏、光栅臂控制 |
| 四路视频监控 | 前视/后视/打标/4号相机实时视频 |
| 数据管理 | 检测项目、焊缝、记录、统计报告的 Access 数据库存储 |
| 报告生成 | 检测报告与统计分析报告输出 |
| 3D 可视化 | 基于 VTK 的三维数据显示 |

### 1.3 运行模式

系统通过 `SysConfig.ini` 中的 `m_i_TOFD_0_Cscan_1` 配置项决定运行模式：

| 值 | 模式 | 说明 |
|----|------|------|
| 0 | TOFD 模式 | 标准 TOFD 超声检测 |
| 1 | C-Scan 模式 | C 扫描成像检测 |
| 2 | 多通道模式 | 多探头并行检测 |
| 3 | 涂层模式 | 涂层厚度检测 |

## 3. 模块详细设计

### 3.1 主入口 Program.cs

**文件：** `Program.cs`

**职责：** 应用程序启动、防重复运行、软件注册验证、模式选择

**核心流程：**

```
Main()
  ├── Mutex 防重复启动检查
  ├── 读取 SysConfig.ini → m_i_TOFD_0_Cscan_1 (运行模式)
  ├── 软件注册验证 (基于网卡 MAC + 序列号 + AES)
  │   └── ClockCryptoLock 类 (AES 时间锁)
  ├── 设置 UI 异常处理 & 线程异常处理
  └── Application.Run(new Frm_Main_C())
```

**AES 时间锁（ClockCryptoLock）：**
- 加密算法：AES
- 锁定依据：网卡 MAC 地址 + 设备序列号
- 时间限制：支持到期时间验证
- 密钥存储：通过混淆存储于代码中

### 3.7 TOFD 数据采集核心 Tofd_DLL

**文件：** `Tofd_DLL/Tofd.cs`

**职责：** TOFD 超声数据采集的核心引擎，集成多种硬件接口

**核心类：**

| 类名 | 说明 |
|------|------|
| `CLTofd` | TOFD 数据采集主类，后台线程持续读取 |
| `CLTofd_BJ` | 北京六维远光探头适配器 |

**CLTofd 数据采集循环：**

```
Read_TOFD() 后台线程:
while (m_iRun != 10)
{
    1. GetDistan()     // 获取当前距离
    2. if (状态 == 0)
       {
           setPeakBuffer()  // 读取波形原始数据
       }
    3. WaitTime()       // 可配置的采集间隔延时
}
```

**GetDistan() 距离获取逻辑（两路来源）：**

```
├── 模拟模式 (BScanMode != 1)
│   └── 距离 = Climb.Trip ± 屏幕偏移 (mm)
│
└── 编码器实时模式 (BScanMode == 1)
    ├── getEncoderValue(0,0/1) → 获取脉冲数
    ├── 脉冲数 × 校准系数 = 实际距离 (mm)
    └── 考虑编码器方向 (m_iEnPos)
    
├── 最终距离校验: _flDis < flMaxDistance/1000
│   └── 设置 m_flDistanc_X / Climb.Trip
```

**硬件集成接口：**

| 接口 | 硬件 | 函数 |
|------|------|------|
| `EM_RIT` | 武汉中科 TOFD 仪器 | `Link()` / `setPeakBuffer()` / `getEncoderValue()` |
| `ECT_DLL` | 涡流检测 | 涡流信号采集 |
| `AnyCardInterface` | 北京超声探头采集卡 | 模拟信号采集 |
| `AnyCardXSharp` | 北京六维远光 | 数字探头数据读取 |
| `HD850_64` | 编码器采集卡 | 距离脉冲计数 |

## 10. 软件注册与授权

**类：** `ClockCryptoLock` (Program.cs)

**授权机制：**

```
┌────────────────────────────────────────────────┐
│  1. 获取本机网卡 MAC 地址                        │
│  2. 获取设备序列号                               │
│  3. 组合 → AES 加密                              │
│  4. 验证授权码是否匹配                            │
│  5. 检查时间锁（到期时间）                        │
│  6. 验证通过 → 启动主程序                         │
│     验证失败 → 显示授权异常提示 → 退出            │
└────────────────────────────────────────────────┘
```

**特点：**
- 绑定硬件（MAC 地址），防止拷贝
- AES 时间锁，支持试用期控制
- 序列号验证，支持多设备授权管理
